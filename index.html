FORMAT NOTES

Know what changes.

The editor patches recognized values and preserves unknown data. Full-game support is based on the supplied Conquest file and public format research; generated files still need an import check in Miliastra.

One envelope, two workflows

20-byte headerSize · version · magic · type · payload length
Protobuf payloadGame sections or exported assets
4-byte footerMagic: 0x0679

Header words use big-endian order. Protobuf numbers use varints and little-endian fixed values. The header size excludes the footer; payload length excludes all 24 envelope bytes.

Dictionaries, IDs, vectors, graphs, terrainInspect and preserve. Full-game editing for these shapes is not enabled.

Preservation comes first

Unknown fields, metadata, reference IDs, and unedited sections remain opaque bytes. Edits only rebuild the affected value and its enclosing length prefixes. A file opened and exported without edits is identical to the original. Reference IDs are not interchangeable with plain integers; dictionaries also contain mirrored values.

Research and limits

Conquest contains additional sections beyond the public schema. Unmapped sections are retained and listed by field number, without guessed meanings. Container version 1 supports edits; other versions open read-only.
