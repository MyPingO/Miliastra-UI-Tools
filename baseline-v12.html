UI Component Exports (.gia)

Template-based GIA

Single Choice Window

Uses a completely untouched Miliastra Single-Choice Window export as the template. It contains only the Floating Interaction Page, Inherent Container, required Close Button, and Single-Choice Window. Formal Variables and List Items are then created in the editor.

Template-based GIA

Modifier Deck Selector

Starts with one blank deck row using the validated Deck Selector component structure and its required internal index list.

Template-based GIA

Floating Page + Tab

Creates a plain Floating Interaction Page with the required Close Button and one Tab component. Define Floating Page Formal Variables, then add, duplicate, delete, and reorder Tab items.

Generated Structure GIA

Structure Definition

Creates a Structure GIA with one String field, then lets you rapidly add, duplicate, delete, reorder, rename, and change field types.

New GIA files use embedded copies of the component exports we already proved can be resized and re-imported. This avoids fabricating the many still-unknown UI metadata fields.

Verified Structure GIA Types

Scalar: Entity, Guid, Int32, Bool, Float, String, Vector3, Army, ConfigReference, EntityReference
Lists: GuidList, Int32List, BoolList, FloatList, StringList, EntityList, Vector3List, ConfigReferenceList, EntityReferenceList, ArmyList
Containers: Struct, StructList, Dict
StructList is confirmed as GIA type code 26. Build New currently keeps Struct / StructList reference fields out of the type picker until referenced-Structure dependency handling is generalized.

Verified Structure Variable Types

Scalar/reference: String, Int32, Float, Bool, Vector3, Entity, Guid, ConfigReference, EntityReference, Army
Lists: StringList, Int32List, FloatList, BoolList, Vector3List, EntityList, ConfigReferenceList, EntityReferenceList, ArmyList
Containers: Struct, StructList, Dict
